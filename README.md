# reporte-gestion-jc
Reporsitorio para publicar un sitio con el HTML del reporte armado por Julian Cappa

## Archivos

- `index.html`: el tablero "Base Instalada y Servicios". Lee `data.json` de la misma carpeta.
- `data.json`: los datos del tablero (Airtable, Zoho CRM y archivos de Tableau, Maestro de Proyectos y sheet de control).
- `DATA_SCHEMA.md`: estructura de `data.json`, columna por columna, y cómo regenerarlo.
